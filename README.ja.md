# handremote

**PC のウィンドウを、スマホのサイズで。**

開いているウィンドウ・ウィジェット・トレイ・サーバーを分類ごとに一覧し、ひとつをタップするとそのウィンドウがスマホの画面サイズに並べ直されて開きます。縮小した画面ではなくアプリがスマホのサイズで描き直されるので、文字は小さくならず、そのままタップして入力できます。

## リモートデスクトップとの違い

| | リモートデスクトップ | handremote |
|---|---|---|
| 単位 | デスクトップ全体 | ウィンドウひとつ |
| サイズ | PC 画面を縮小 | ウィンドウをスマホのサイズに並べ直す（閉じると元のサイズ） |
| 状態 | 画素のみ | トレイ、待ち受けポート、サーバープロセスを一覧で |
| 入力 | タッチをマウス座標に | タップ = クリック、長押し = 右クリック、ドラッグ = スクロール、入力欄で日本語も |

## はじめかた（Windows 10/11）

```sh
npm install -g github:YangJongWon/handremote
handremote
```

ターミナルの QR コードをスマホのカメラで読み取ります（同じ Wi-Fi）。PC で **http://localhost:9100/connect** を開くと QR が大きく表示されます。最初の一度だけ証明書の警告を進めてください。

PC で [Tailscale](https://tailscale.com) にサインインしていれば、外出先でも使える `https://<PC名>.<tailnet>.ts.net:9443` も表示されます。**自分の tailnet の端末だけ**が接続できます。公開リンク（Funnel）はあえて用意していません。

## スマホの画面

| 分類 | 内容 | タップすると |
|---|---|---|
| ウィンドウ | タスクバーにあるウィンドウ。プロセス、CPU、メモリ | スマホのサイズで開く |
| ウィジェット | 最前面ウィンドウ、ツールウィンドウなど | 開く（サイズを変えられないものは画面に合わせて表示） |
| トレイ | 通知領域のアイコン（隠れたものも） | PC でクリックし、開いたメニューやウィンドウを表示。長押しで右クリック |
| Web アプリ | ページを返す localhost ポート | スマホでそのアプリを開く |
| サーバー | ポートで待ち受けているプロセス | パス、コマンドライン、開始時刻 |
| セキュア画面 | SYSTEM ヘルパーがあるとき、UAC 確認やロック画面 | 自動で開く |

ウィンドウ表示中: **タップ** クリック、**長押し** 右クリック、**1 本または 2 本指ドラッグ** スクロール、**✥** ドラッグモード、下の **入力欄** でどんな文字でも入力（空で送ると Enter）、補助キー Esc・Tab・⌫・Del・Enter・矢印・Ctrl/Alt/Shift/Win・Home・End・PgUp・PgDn・F5。**元のサイズ** でウィンドウを戻して縮小表示します。

ウィンドウのサイズは変える前に `~/.handremote/restore.json` に記録され、閉じたとき、handremote の終了時、異常終了後は次の起動時に元に戻ります。

## SYSTEM ヘルパー（任意）

管理者ウィンドウ、UAC 確認、ロック画面まで扱うには一度だけインストールします。

```sh
handremote helper install     # UAC の承認 1 回
handremote helper status
handremote helper uninstall   # タスク、ファイル、ポリシー変更をすべて戻す
```

Chrome リモート デスクトップのホストと同じ構成です。ネットワークポートは開かず、SYSTEM とインストールしたユーザーだけが開ける名前付きパイプと、そのユーザーだけが読める秘密値で handremote と通信します。実行ファイルは管理者だけが変更できる `%ProgramData%\handremote` から動きます。handide の公開リンクから開いたときはヘルパーを使いません。

> [!IMPORTANT]
> ヘルパーがあると、リンクを持つ人はロック画面に PIN を入力できます。リンク（`~/.handremote/token`）はパスワードと同じように扱い、`handremote --new-token` で無効にできます。

## handide と一緒に

[handide](https://github.com/YangJongWon/handide) と同じ PC で動いていると、handide のメニューに **PC 画面** が現れ、handide のアドレスとトークンで開きます。

## 対応範囲と既知の制限

- **Windows 10/11** のみ。macOS は今後。
- 一部の GPU 描画のウィンドウは黒く映ることがあり、そのときは画面に見えている部分を代わりにコピーします。
- 入力の前にそのウィンドウを前面に出します。出せないときや別のウィンドウが覆っているときは、**別のウィンドウに入力せず**スマホに知らせます。
- `npm run check` は専用のメモ帳で一覧、スマホサイズの配置、韓国語入力、タップ、サイズの復元を Pixel 7 と iPhone 14 のエミュレーションで確認します。SYSTEM ヘルパーの UAC・ロック画面は実機で別に確認が必要です。
